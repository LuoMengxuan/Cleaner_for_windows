# VIncinzo 磁盘清理

一个面向 Windows 新手的 Qt Widgets 磁盘空间与大文件清理工具。它坚持“先查看、再确认、可恢复”的清理方式，不会直接永久删除文件。

界面采用安全中心式仪表盘布局，清晰展示守护状态、磁盘空间、扫描进度与文件处理建议。

## 主要功能

- 扫描任意已挂载磁盘，按 100 MB、500 MB、1 GB 或 2 GB 查找大文件。
- 显示磁盘已用空间与剩余空间，系统托盘图标实时标注 C 盘使用率。
- 结果按文件大小排序；可打开文件位置、复制完整路径，再自行决定是否清理。
- 自动标注视频、压缩包、镜像、图片、文档、备份与程序文件类型，帮助新手快速判断。
- 支持“只看可清理文件”和右键快捷菜单，减少无关信息干扰。
- 扫描后自动打开“扫描文件分类”页面，四个纵向折叠按钮可分别展开缓存、视频照片、文稿压缩、系统软件配置；所有分类同时展开时可通过滚动条浏览。
- 分类页采用安全中心式布局，顶部展示扫描完成状态，统计卡片一眼区分默认可清理、待确认与已保护的文件数量。
- 分类窗口可直接点击文件路径打开所在位置；软件配置和系统关键文件仅展示、不可删除。
- 在分类窗口内即可确认并移入回收站；关闭窗口返回主页时会自动刷新当前磁盘状态。
- 选中的文件会移入 Windows 回收站，不做永久删除。
- 保护系统目录、程序目录、用户 AppData、驱动与可执行文件，避免新手误删关键内容。
- 内置新手三步指南、状态提醒与友好对话框。
- 首次启动支持 10 位离线激活码校验，无需连接网络；激活成功后无需重复输入。
- 激活码的校验规律、生成步骤与 100 个可发放激活码见 `activation_codes.txt`。
- 主界面由 `src/mainwindow.ui` 定义；扫描分类子界面由 `src/categoryreviewdialog.ui` 定义，均可直接在 Qt Creator 的设计器中编辑。

## 打开与构建

1. 在 Qt Creator 中打开 `Cpan_hdx.pro`。
2. 选择可用的 Desktop Qt MSVC 套件。
3. 构建输出目录配置为 `D:\Qt_out`；构建完成后可运行 `D:\Qt_out\VincinzoCleaner.exe`。

## 发布版

可分发版本位于 `D:\Qt_out\release`。其中包含 EXE、Qt 运行库、平台插件和 `vc_redist.x64.exe`。

## 安全提示

扫描整个磁盘可能耗时数分钟；无访问权限的目录会由系统自动跳过。程序会保护常见关键文件，但仍建议在删除前使用“打开文件位置”核对用途。
