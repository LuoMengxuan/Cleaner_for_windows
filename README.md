# 哈丁汪C盘清理器

基于 Qt Widgets 的 Windows 磁盘空间与大文件清理工具。

## 功能

- 后台递归扫描 C 盘，可选 100 MB / 500 MB / 1 GB / 2 GB 阈值。
- 按地址和大小列出大文件，不阻塞界面。
- 系统关键目录和分页/休眠文件只展示，不允许勾选。
- 用户勾选后再次确认，文件默认移入 Windows 回收站，不直接永久删除。
- 系统托盘图标实时显示 C 盘已用百分比，悬停显示所有磁盘容量。
- 主界面每 15 秒刷新所有已挂载磁盘空间。
- 主窗口由 Qt Designer 文件 `src/mainwindow.ui` 定义，可在 Qt Creator 的“界面文件”分组中直接编辑。

## 在 Qt Creator 中打开

使用 Qt Creator 打开 `D:\Cpan_hdx\Cpan_hdx.pro`。工程树会显示 `src` 目录中的全部头文件和 C++ 源文件，之后选择本机 Qt 套件自行配置、构建和运行即可。

## 注意

扫描整个 C 盘可能持续数分钟，受 Windows 权限限制而无法访问的目录会被自动跳过。清理前请核对文件用途；程序不会自动判断所有第三方应用数据是否仍然需要。
